# Analytics Skill Project

This repository contains a self‑contained project designed to showcase skills relevant to business analysts, program managers and data analysts. It includes a synthetic business dataset, an exploratory analysis notebook with visualizations and predictive modelling, and a `requirements.txt` file listing all dependencies. The project is ready to use out of the box—simply install the dependencies and open the notebook.

## Project structure

```
.
├── synthetic_business_data.csv   # Synthetic dataset (transaction records with categorical and numeric features)
├── analysis.ipynb                # Jupyter notebook with EDA, visualizations and predictive models
├── requirements.txt              # Python packages required to run the notebook
└── README.md                     # Project overview and instructions (this file)
```

## Synthetic dataset

The dataset contains 1,000 transaction records from a fictional company. It is entirely synthetic—no real customer or business data is included. Each row represents a single transaction and includes:

| Column | Description |
| --- | --- |
| `Date` | Timestamp of the transaction (2019–2022) |
| `Product_Category` | Categorical variable indicating the product type (Electronics, Furniture, Office Supplies, Clothing, Food) |
| `Region` | Geographic sales region (North, South, East, West) |
| `Customer_Segment` | Customer segment (Consumer, Corporate, Small Business) |
| `Sales` | Revenue generated by the transaction (float) |
| `Quantity` | Number of units sold (integer) |
| `Discount` | Discount applied to the sale (0–0.30) |
| `Marketing_Spend` | Estimated marketing expenditure attributed to the transaction |
| `Profit` | Profit generated from the transaction (calculated from sales, quantity, discount and a random margin) |
| `High_Performance` | Binary flag indicating whether the transaction falls in the top 25 % of profits (1) or not (0) |

The dataset is created using random sampling with sensible distributions for each feature. Because it is synthetic, you can adapt or extend it without privacy concerns.

## Notebook: `analysis.ipynb`

The Jupyter notebook performs the following steps:

1. **Load and preview the data** – read the CSV into a Pandas DataFrame, parse dates and inspect the first few rows.
2. **Summary statistics** – display information about data types and compute descriptive statistics for numeric columns.
3. **Exploratory visualizations** – create box‑plots of sales by product category and profit by region, a correlation heatmap for numeric features and a time‑series line chart of monthly total sales and profit.
4. **Predictive modelling** – build two machine‑learning models:
   - A **linear regression** model to predict `Profit` using sales, quantity, discount, marketing spend and categorical variables (with one‑hot encoding).
   - A **logistic regression** model to predict `High_Performance` as a binary target.
   The notebook splits the data into training and test sets, fits each model and prints evaluation metrics (R² and RMSE for regression, accuracy and a classification report for classification).

You can run the notebook cell‑by‑cell to explore the dataset and experiment with different model configurations. Feel free to extend the analysis or try additional algorithms.

## Setup and usage

1. **Clone the repository** (or download the files as a ZIP).
2. **Create a Python environment** (optional but recommended) using [virtualenv](https://virtualenv.pypa.io/) or [conda](https://docs.conda.io/). Activate the environment.
3. **Install dependencies**:

   ```bash
   pip install -r requirements.txt
   ```

4. **Launch Jupyter Notebook**:

   ```bash
   jupyter notebook
   ```

5. Open `analysis.ipynb` in your browser and run the cells.

The notebook is executed in advance, so you can immediately view the results. To reproduce or extend the analysis, clear the outputs and execute the cells.

## Extending the project

- **Feature engineering** – create new variables (e.g., month, year, season) from the `Date` column or group similar product categories. Experiment with interaction terms or polynomial features.
- **Model selection** – try decision trees, random forests or gradient‑boosting methods for regression and classification. Compare performance using cross‑validation.
- **Visualization** – build dashboards or interactive visualizations using tools like `plotly`, `dash` or `tableau` to present findings.
- **Reporting** – summarise insights and recommendations in a report or presentation aimed at stakeholders. Consider the business implications of high‑profit transactions and marketing spend.

Feel free to fork this repository and adapt it for your own portfolio. Contributions are welcome via pull requests.

## Future work

This project can be extended by integrating real-world public datasets, developing dashboards, or deploying models as APIs. For example, you could connect the predictive model to a simple web app that allows stakeholders to input transaction details and receive profit predictions. Additionally, experimenting with time-series forecasting (e.g., ARIMA, Prophet) on the monthly aggregated sales could provide insights into future trends.
